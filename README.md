# EcoRover – Autonomous Waste Collection Rover

## Project Overview
EcoRover is a proposed low-cost autonomous waste-collection rover designed to identify and collect litter in campus environments, pavements, and other suitable outdoor spaces.

The project combines mechanical design, robotics, electronics, and embedded programming to explore practical solutions to waste management.

## Project Objectives
- Develop a compact four-wheel-drive mobile rover.
- Design an arm-inspired robotic gripper for picking up litter.
- Incorporate an onboard waste collection bin.
- Explore autonomous navigation and litter detection.
- Develop an affordable working prototype.

## Key Engineering Areas
- Mechanical design and CAD modelling using Autodesk Inventor
- Chassis and drivetrain design
- Robotic arm and gripper mechanisms
- Electronics and embedded systems
- C/C++ programming and autonomous control

## Development Status
**Currently in the design and development stage.**

## Project Vision
To develop an affordable and practical robotic solution that contributes to cleaner environments through engineering innovation.
